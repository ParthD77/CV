# Visualizer

A minimal architecture abstraction workspace. React + TypeScript + React Flow, running on Vite.

## Run

```sh
npm install
npm run dev
```

Open the local address printed by Vite. Use `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 4180 --strictPort` to use the preview port explicitly.

## First slice

- Logical ownership folders, scoped left-to-right graphs, upstream references.
- Select nodes for evidence; double-click or use the inspector to navigate.
- Search, breadcrumbs, history, zoom and fit.
- Curated GetOut sample: Explore filtering, pin selection, shared data, location.
- Local folder import: deterministic JSX event-binding extraction using the TypeScript AST. Project code is not executed or uploaded.

The sample is manually curated from inspected source, not generated by the importer. Imports currently identify JSX files and explicit event bindings, not full architecture. Name matches are only handler candidates, not proven resolution. Other domains remain unassessed. Limits and unsupported cases are reported. State is in memory; reload restores the sample.

## Structure

- `src/model.ts`: shared graph model and curated sample.
- `src/importer.ts`: source extraction, separate from presentation.
- `src/App.tsx`: ownership navigation, graph and inspector.
- `src/styles.css`: workbench appearance.
